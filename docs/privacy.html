Политика конфиденциальности

Приложение «Моя аптечка» · версия 1.0.0

1. Общие сведения

«Моя аптечка» — мобильное приложение для домашнего учёта лекарств и расписания приёма. Приложение не ставит диагнозы и не заменяет консультацию врача или фармацевта. Пользователь самостоятельно отвечает за корректность введённых данных. Регистрация аккаунта не требуется.

2. Какие данные обрабатываются локально

Данные аптечки, профилей семьи, курсов, приёмов, сканов, фотографий упаковок и резервных копий хранятся локально на устройстве пользователя (SQLite и файлы приложения). Облачная синхронизация и передача содержимого аптечки на серверы разработчика не используются.

3. Камера и сканер

Камера используется только после того, как пользователь открывает сканер кода на упаковке. Отсканированные коды сохраняются локально и не загружаются на серверы разработчика.

4. Локальные уведомления

Напоминания о приёме реализуются локальными уведомлениями на устройстве (без обязательного push-сервера разработчика). Разрешение на уведомления запрашивается в контексте настройки напоминаний.

5. Резервное копирование

Резервная копия создаётся локально в виде файла. Пользователь сам выбирает, куда сохранить или откуда восстановить файл через системный интерфейс. Файл может содержать чувствительные данные аптечки и не шифруется.

6. Аналитика (AppMetrica)

Приложение использует SDK AppMetrica (Яндекс) для технической аналитики использования и стабильности: обобщённые события и технические сведения об устройстве/сессии согласно политике AppMetrica.

В пользовательские события аналитики не передаются: названия лекарств, имена членов семьи, заметки, пользовательский текст покупок, отсканированные коды (включая GTIN / серийные номера / сырые QR и DataMatrix), содержимое дневника приёма и тексты уведомлений о лекарствах.

Подробнее: условия AppMetrica.

7. Реклама (Yandex Mobile Ads / РСЯ)

Приложение использует SDK Yandex Mobile Ads для показа рекламы (баннер на отдельных основных экранах и редкий interstitial). Рекламный SDK может обрабатывать технические идентификаторы устройства (в том числе Advertising ID при наличии) и сетевые данные в соответствии с политикой Яндекса для мобильной рекламы.

Приложение не передаёт в рекламный слой названия лекарств, имена членов семьи, отсканированные коды и содержимое медицинского дневника.

Реклама не показывается в критических сценариях приёма лекарств, сканирования, создания/редактирования курсов и резервного копирования.

8. Сеть и офлайн

Базовые функции учёта лекарств рассчитаны на работу без интернета. Без сети реклама и аналитика могут быть недоступны или отложены; ошибки этих SDK не мешают работе приложения.

9. Контакты и права пользователя

По вопросам конфиденциальности и поддержки: rustore-alex1c@yandex.ru.

Пользователь может удалить данные приложения стандартными средствами Android (очистка хранилища / удаление приложения).
