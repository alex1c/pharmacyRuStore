Политика конфиденциальности

Приложение «Моя аптечка» · редакция для Phase 0 (черновик перед публикацией)

1. Общие сведения

«Моя аптечка» — мобильное приложение для домашнего учёта лекарств и расписания приёма. Приложение не ставит диагнозы и не заменяет консультацию врача или фармацевта. Пользователь самостоятельно отвечает за корректность введённых данных.

2. Какие данные обрабатываются сейчас

На текущем этапе данные аптечки, профилей и связанных записей хранятся локально на устройстве пользователя (SQLite). Облачная синхронизация, регистрация аккаунта и передача содержимого аптечки на наши серверы не используются.

3. Сеть и сторонние сервисы

Базовые функции учёта лекарств рассчитаны на работу без интернета. В будущих версиях могут быть подключены технические сервисы аналитики (например, AppMetrica) и рекламные SDK (например, РСЯ / Yandex Mobile Ads). Если такие сервисы будут включены, политика будет дополнена описанием категорий технических данных, целей обработки и ссылками на политики партнёров до публикации соответствующей версии.

4. Права пользователя

Пользователь может удалить данные приложения стандартными средствами Android (очистка хранилища / удаление приложения). Отдельный канал поддержки и адрес электронной почты будут указаны перед релизом в RuStore.

5. Изменения документа

Мы можем обновлять эту политику при изменении функциональности приложения. Актуальная версия будет доступна в материалах магазина приложений и/или внутри раздела «О приложении».
