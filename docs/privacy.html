Политика конфиденциальности

Приложение «Моя аптечка» · редакция Phase 8B (AppMetrica + РСЯ)

1. Общие сведения

«Моя аптечка» — мобильное приложение для домашнего учёта лекарств и расписания приёма. Приложение не ставит диагнозы и не заменяет консультацию врача или фармацевта. Пользователь самостоятельно отвечает за корректность введённых данных.

2. Какие данные обрабатываются локально

Данные аптечки, профилей семьи, курсов, приёмов, сканов и резервных копий хранятся локально на устройстве пользователя (SQLite и файлы приложения). Облачная синхронизация, регистрация аккаунта и передача содержимого аптечки на серверы разработчика не используются.

3. Аналитика (AppMetrica)

Приложение использует SDK AppMetrica (Яндекс) для технической аналитики использования и стабильности: обобщённые события и технические сведения об устройстве/сессии согласно политике AppMetrica.

В пользовательские события аналитики не передаются: названия лекарств, имена членов семьи, заметки, пользовательский текст покупок, отсканированные коды (включая GTIN / серийные номера / сырые QR и DataMatrix), содержимое дневника приёма и тексты уведомлений о лекарствах.

Подробнее: условия AppMetrica.

4. Реклама (Yandex Mobile Ads / РСЯ)

Приложение использует SDK Yandex Mobile Ads для показа рекламы (баннер на отдельных основных экранах и редкий interstitial). Рекламный SDK может обрабатывать технические идентификаторы устройства (в том числе Advertising ID при наличии) и сетевые данные в соответствии с политикой Яндекса для мобильной рекламы.

Приложение не передаёт в рекламный слой названия лекарств, имена членов семьи, отсканированные коды и содержимое медицинского дневника.

Реклама не показывается в критических сценариях приёма лекарств, сканирования, создания/редактирования курсов и резервного копирования.

Подробнее о рекламных сервисах Яндекса см. актуальные правовые документы Яндекса для рекламных технологий / РСЯ.

5. Сеть и офлайн

Базовые функции учёта лекарств рассчитаны на работу без интернета. Без сети реклама и аналитика могут быть недоступны или отложены; ошибки этих SDK не мешают работе приложения.

6. Права пользователя

Пользователь может удалить данные приложения стандартными средствами Android (очистка хранилища / удаление приложения). Отдельный канал поддержки и адрес электронной почты будут указаны перед релизом в RuStore.

7. Изменения документа

Мы можем обновлять эту политику при изменении функциональности приложения. Актуальная версия будет доступна в материалах магазина приложений и/или внутри раздела «О приложении».
