1. GitHub → repository **Settings** → **Pages**
2. Build and deployment: Deploy from a branch
3. Branch: `main` / folder: `/docs`
4. Save and wait for the Pages site to go live
5. Open the privacy URL and confirm the support email `rustore-alex1c@yandex.ru`

No separate `gh-pages` branch is required when using `/docs` on `main`.
